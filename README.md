# dsh-fnos-music V3

飞牛音乐（fnOS Music）的 DeepSeek Harness 插件。V3 把主面板重构成**原版飞牛音乐 Web 式交互**，并在纯本地曲库之上加入收听历史、统计、成员 profile、场景 BGM、连续本地 DJ、语音指令、Agent 审计与流量统计。当前补丁版本 **3.0.2** 修复了歌手页专辑点开后不显示歌曲的问题；3.0.1 修复了最近播放重复与历史条目无法继续播放。

> V3 只连接你自己的 fnOS 曲库。**不内置、不提供任何在线音源**；可选在线源子插件不在本次交付中。音频由本机 DSH Host 同源 Range 中继输出，不缓存、不转码、不外传。

## 1. 原版 Web 交互

主面板不再是 V2 的四 Tab，而是原版应用结构：

- **顶栏**：后退/前进、品牌、全局搜索、连接状态、设备胶囊、刷新、浏览器打开、悬浮播放器、成员头像、可选语音。
- **左侧导航**：首页、正在播放、最近播放；音乐库：歌曲、专辑、歌手、歌单、文件夹、我喜欢的音乐；工具：场景、统计、设置。
- **内容区**：首页 Hero/最近播放/为你推荐/最新专辑/歌手/歌单；歌曲表格；专辑/歌手/歌单卡片与详情；全局搜索；最近播放；统计；场景；设置。
- **右侧正在播放**：当前曲 + 接下来；窄容器自动隐藏。
- **底部播放栏**：封面/歌名/歌手、进度、上一首/播放暂停/下一首、红心、随机/循环/单曲、音量、队列、全屏、悬浮。
- **交互**：单击行播放、hover 播放、右键菜单（播放/下一首/加入队列/加入歌单/红心/打开专辑/歌手）、复选框多选、Shift 范围选择、批量加入队列/歌单/红心、`/` 聚焦搜索、`Alt+←/→` 后退/前进、`Esc` 关闭菜单。

视觉使用 DSH 主题 token（明暗主题跟随 DSH），不是旧版硬编码暖色的像素复刻；布局与操作路径对齐原版。旧版的 demo 曲库、全量加载、密码会话和硬编码主题没有带回来。

## 2. V3 本地能力

### 收听历史与统计
- 每成员独立的本地历史，记录曲目、歌手、专辑、封面、音质、时长、实际收听时长、完成状态、设备和来源。
- “最近播放”视图按 `trackId` 去重（同一首歌只保留最后一次播放），原始逐次播放记录继续保留给统计和 Agent 历史查询。
- 历史条目保存可重建的曲目快照；插件重启/曲库缓存失效后，点击旧历史仍可直接播放，不需要先搜索。
- 切歌/暂停/进度/结束都会更新；2 秒 debounce 原子写盘，损坏文件不阻塞播放。
- 7 天/30 天/全部：播放次数、收听时长、独立歌曲、活跃天数、每日/24 小时分布、Top 歌曲/歌手/专辑/流派、音质分布。
- 历史/统计可在设置或统计页清空；Agent 清空需要 confirmToken。

### 成员 profile
- 最多 8 个本地成员；历史、统计、推荐按成员隔离，播放队列共享。
- **不是身份认证**：成员切换只是本地 UI 隔离，DSH Profile 仍是安全边界。
- 顶部头像菜单/设置里切换、创建、重命名、删除；删除最后一个会被拒绝。

### 推荐、场景与连续 DJ
- 画像由当前成员历史 + 收藏派生，推荐本地曲目；无历史时回退收藏/无损/曲库首页。
- 场景：`auto`（按本地时间）、晨间、专注、夜晚、深夜、纯音乐。场景只使用本地时间、画像和元数据；**不请求天气/定位/在线内容**。
- 场景会替换队列并启用连续本地 DJ；不会在后台自动启动。
- 连续 AI DJ：模型可用 `fnos_music_dj` 提供本地 trackIds 池或场景；Host 在队尾自动续播/按场景/画像补货，不需要模型每首回复聊天。插件内部不调用 LLM、不生成音频。

### 语音指令（可选）
- 默认关闭；开启且浏览器支持 `SpeechRecognition` 时显示麦克风。
- 只发送识别出的文本到同源 `/voice`，由 Host 的确定性意图解析执行：暂停/继续/上一首/下一首/静音/音量/随机/循环/收藏/播放某曲/打开歌词/打开悬浮。
- 插件不保存 transcript；音频可能由浏览器/系统语音服务处理，开启前请阅读设置里的提示。不支持 ASR 的浏览器直接隐藏麦克风。

### Agent 权限与审计
- 设置可关闭“允许 Agent 写操作”：Agent 仍可搜索/播控/队列，但不能改歌单、红心、智能歌单、历史或成员。
- 所有 Agent 写操作写入本地审计（工具、动作、目标、结果），不记录曲库内容、token、Cookie 或完整参数。
- UI 自身的写操作不经过 Agent 开关，仍始终有 UI 确认。

### 流量统计
- 传输层记录请求数、错误、响应字节、耗时、实际路径（`fnid`/`direct`/`unix`/`auto`）。
- 不记录 query、Cookie、token；`traffic.json` 保留 60 天；音频流字节按 content-length 近似。
- 设置可关闭统计；UI 统计页可清空。

### 大曲库
- 所有列表服务端分页，单页 50；首页只取小页；不把整个曲库加载进浏览器。
- 歌曲表使用 `content-visibility` + 自动加载哨兵，滚动接近底部时加载下一页。
- 过滤/文件夹/歌手扫描仍受 10 页上限约束并返回 `scanned/truncated`。

### V2 能力保留
- FNID 中继、局域网直连、Unix Socket、自动择优；三档连接探测。
- 歌单完整 CRUD、批量添加/移除、插件 JSON/M3U8 导入导出。
- 歌词（服务端 LRC；双语/逐字内容存在时）、频谱、MediaSession、全局快捷键、悬浮播放器。
- 后台设备探测、请求日志、封面/歌词缓存、token 失效提示。
- V2 的 12 个工具和 V3 新增的 4 个工具共 **16 个**。

## 3. 安装与启用

插件作为 DSH Profile bundle 安装/链接；`package.json` 版本 `3.0.0`。

```bash
# 在 DSH 的插件管理/Profile 中启用 dsh-fnos-music
# 或本地开发：
cd /path/to/dsh-fnos-music
pnpm build
```

启用后左侧栏出现“飞牛音乐”。首次进入在连接页添加 FNID 或局域网地址；也可以在设置里添加/切换设备。凭证只保存在当前 DSH Profile 的 credential store，浏览器拿不到 token。

## 4. 数据与隐私

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 设备/FNID/token、成员、设置 | DSH credential store `<profile>` | 不进入浏览器 |
| 收听历史 | `$DSH_HOME/data/dsh-fnos-music/<profile>/history-<listener>.json` | 每成员一份，最多 5000 条 |
| 审计 | 同目录 `audit.json` | 最多 1000 条 |
| 流量 | 同目录 `traffic.json` | 最多 60 天 |
| 封面/歌词缓存 | `$DSH_HOME/cache/dsh-fnos-music/<profile>` | 清缓存不会删历史/审计/流量 |

- 不写 NAS 数据库、不改文件、不下载音频、不把音频/曲库元数据发到外部。
- 卸载插件后本地历史/审计/流量文件仍保留；需要彻底清理时手动删除上述 data 目录。历史、审计、流量分别有 UI/接口清理入口。
- 在线源和天气适配都不在本版本。

## 6. 安全边界

- 浏览器只访问同源 `/fnos-music/*`；token 只在 Host 内存/credential store。
- 所有 Web 路由有 DSH 会话鉴权围栏；流媒体/封面/歌词通过 Host 同源中继。
- 自签名证书只对单个设备显式允许；不关闭全局 TLS 校验。
- 歌单导入只解析 JSON/M3U8 文本，不读任意文件路径；大小/数量有限制。
- 流量/审计不记录敏感 query/cookie/token；语音只接收文本、不存 transcript。
- 成员 profile 不是鉴权；在线源子插件若未来引入，必须作为独立 opt-in 包单独安全/版权评审。

## 7. 已知限制

- 官方 fnOS API 没有播放器状态/队列/控制接口；官方 App 与 DSH 的实时播放状态不互通，插件维护自己的共享队列。
- 专辑/歌手详情在部分固件的 `/album/detail` 中不含曲目；3.0.2 改用 `track/album-detail/list` 与 `track/artist-detail/list` 获取曲目，避免依赖曲库前 500 首扫描。
- 官方网页端不支持扫码登录；本插件用 FNID/局域网直连 token。
- 部分固件的 `/album/detail` 不含曲目；3.0.2 优先使用 `track/album-detail/list`，仅老固件回退专辑名搜索。不同固件字段仍可能不同。
- 不读取 NAS 本地 LRC 文件；歌词依赖服务端 LRC。
- 歌单无官方文件格式、无 reorder/move、无法改封面；插件 JSON/M3U8 不保证官方 App 可导入。
- 在线音源、天气场景、官方 App 双向同步不在本版本。
- 语音识别依赖浏览器能力；不支持时只保留文本/Agent 操作。
- 大曲库目前是分页 + 自动加载 + `content-visibility`，没有建立全库本地索引；过滤扫描有 10 页上限。

- 桌面 Web 面板在真实 DSH UI 中验证：4 个 slot、首页/歌曲/专辑/歌手/歌单/文件夹/收藏/正在播放/场景/统计/设置渲染，搜索/详情/右键/多选/统计图无控制台异常；最近播放按歌曲去重，刷新后点击旧历史可直接播放。
- 3.0.2 的专辑/歌手原生曲目端点已通过 mock 与单元测试；本次真实 NAS 验证时设备处于离线状态，恢复后需再跑一次实机歌手→专辑页面。
- 仍需实机确认：真实音频声卡/MediaSession、频谱支持、不同浏览器语音识别、真实官方 App 状态、极端大曲库（>10k）长列表。
- 最近播放去重只影响视图，不重写历史文件；统计仍按真实播放次数计算。

## 9. 在线音源（明确不在 V3.0）

原始路线图里的“可选在线音源子插件”需要用户自行部署合法外部桥，涉及版权、SSRF、音频转发和独立安全评审。V3.0 **不实现、不内置、不提供任何音源 provider**。未来如做 `dsh-fnos-music-online`，必须是独立 opt-in 包、用户自建合法源、单独审批，不能把在线音频混进本插件。
